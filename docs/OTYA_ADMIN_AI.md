# OTYA Admin Assistant

The Admin Assistant is private and separate from public Ask OTYA.

It is for authorized OTYA administrators and can help with:

- system health and crashes
- support messages and reply drafts
- releases and update status
- remote configuration and feature rollouts
- connected admin tools
- summaries and operations reports

Admin actions must keep existing authorization checks. External writes should require clear approval. Public Ask OTYA must never receive admin-only context, private support mail, tokens or secrets.
