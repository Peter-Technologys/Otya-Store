- [ ] Next.js lint/type/build passes.
- [ ] Homepage presents OTYA as one product, not a suite of Player + AI apps.
- [ ] OTYA page includes visible product-interface imagery.
- [ ] Support embeds Ask OTYA through the existing AI endpoint and has an offline/unavailable fallback.
- [ ] Remote config keeps offline playback allowed.
- [ ] Remote feature NEW badges are versioned; seen state remains local to Android.
- [ ] AI/search settings describe embedded, local-first behavior.
- [ ] Privacy/terms/support links point to OTYA-specific pages.
