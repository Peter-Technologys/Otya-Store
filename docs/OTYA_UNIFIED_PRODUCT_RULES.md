# OTYA unified product rules

The website, Cloudflare services and Android app must present one OTYA product.

- Primary Android navigation: Video, Music, Me.
- Transfer, files, private media, converter, playlists, history, tools, personalization and storage are grouped capabilities, not separate products.
- Account is supporting identity infrastructure.
- AI is embedded intelligence for Search and Support; it must not be marketed as a competing standalone app in the primary OTYA journey.
- The website should show the actual OTYA interface and explain the same hierarchy as the app.
- Local playback, scanning, themes and device-to-device transfer must not depend on cloud availability.
- Feature-discovery badges may be remotely versioned, but seen state is local.
- Local media names/lists are not uploaded to implement NEW badges.
