# OTYA Account scope

OTYA Account supports the OTYA app.

It handles:

- sign in and registration
- email verification and password recovery
- Google sign in
- sessions and security
- optional linked identities
- backup and connected features

It must not be required for local playback, local library scanning or basic offline use.

Public wording should say "OTYA Account" or "Sign in to OTYA", not present the account as a separate product.
